# pet_gtbiluan_acandrade

Personal Expense Tracker Final Project

## Getting Started

A Mobile Development Final project.

Required Features:



- Login and registration using Firebase Authentication, 
- Add, display, edit, and delete records using Cloud Firestore, 
- Form validation using Form and TextFormField, 
- Lists using ListView and GridView, 
- Selection controls: Checkbox, Radio, Switch, and Dropdown Button, 
- Buttons: Elevated Button, Outlined Button, Text Button, and Floating Action Button, 
- Navigation using Navigator, Drawer, Bottom Navigation Bar, or TabBar, 
- Messages using Snack Bar, Alert Dialog, and Bottom Sheet, 
- Image upload using Firebase Storage, on the free plan only. 
- Real-time data display using Stream Builder
